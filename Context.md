# Context

## What this is
we build and run e-commerce store websites for physical product companies

## Purpose
Make quality repeatable so it does not depend on memory. Each stage has a fixed input, a fixed job, and one file as output.

## Do
- Read the stage's Context.md before producing anything.
- Use the prior stage's output as the input. Cite it when you deviate.
- Ask when a required input is missing.
- Write plain, scannable markdown.

## Avoid
- Inventing facts, metrics, or figures. Cite a source or ask.
- Skipping a stage, or merging two stages into one file.
- Preamble, recap, and filler.
- Loading files the current stage does not name.
